政策テーマ「周辺」の割安小型株スクリーニング

作成 2026-08-06／母集団：東証プライム・スタンダード・グロース 3,702 銘柄のうち 条件①〜⑥通過 101 銘柄（基準日 2026-07-17）／データ：J-Quants API V2（JPX公式）[⑤]

この一覧の作り方

1. 母集団：条件①〜⑥のみ

STRATEGY.md の8条件のうち、相対条件⑦（直近営業増益率が上位1/3）と⑧（6ヶ月モメンタムが上位1/3）は 母集団から外しました。テーマを重ねると該当が数銘柄まで減るためです。 ⑦⑧は足切りではなく、各銘柄の参考順位として表示しています。

  • ① PER ≤ 15倍 ／ ② PBR ≤ 1.5倍（いずれも未調整終値ベース）
  • ③ 売上高CAGR ≥ 4% ／ ④ 営業利益CAGR ≥ 4%
  • ⑤ 自己資本比率 ≥ 40% ／ ⑥ 時価総額 ≤ 600億円

2. テーマとの距離：本丸を外し、3経路で拾う

テーマ名で検索して出てくる銘柄は、その時点で既に買われている可能性が高い。そこで接続経路を次の3つに分けました。

  1. 裏方（部材・工事・保守）── 装置本体ではなく、その部品・据付工事・メンテを担う
  2. 川下（テーマ投資の受け手）── テーマ企業に納入する側ではなく、投資の結果として仕事が増える側
  3. 共通因子（設備投資量・素材需要）── テーマ名ではなく「設備投資が増えるか」「素材が要るか」で拾う

3. 織り込み度：6ヶ月モメンタムの母集団内順位

「まだ織り込まれていない」を、101銘柄の中での6ヶ月株価モメンタム順位で測っています。 下位1/3を未織り込み、上位1/3を織り込み進行と表示。各テーマ内は順位の低い順に並べています。 順位が低いことは「安く買える」と同時に「売られている理由がある」ことも意味します。どちらかは個別に確かめる必要があります。

4. 事業内容の確認状況（重要）

定量データはすべて J-Quants API V2 [⑤] の一次データで、再現可能です。 一方「その企業が何をしているか」は、公式サイト [②] を確認できた6銘柄を除き、33業種と社名からの仮説です。 各カードにバッジで区別しています。仮説の銘柄は、個別の定量レポート／有報定性レポートを作る段階で 一次情報による確認が必須です。（作成時、木村化工機のドメイン推定が別会社に当たったため、 推定でのURL特定は行わず未確認のまま残しています）
